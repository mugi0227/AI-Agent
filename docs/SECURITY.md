# セキュリティ境界と運用条件

このアプリは単一の会社PC・単一ユーザー向けの試験実装です。自作したこと、テストが通ったこと、Bedrockを使ったことは、組織の承認や完全な安全を意味しません。

## 強制している制約

- 収集・送信・処理地域・定期推論・bridgeは初期無効。AIに設定や承認を変更するツールはない。
- 読み取りは許可ルート・拡張子・サイズを制限し、シンボリックリンク/ジャンクション経由と状態ディレクトリ、代表的な認証ファイルを拒否する。
- 推論先は構成されたBedrock host/base pathのみ。HTTP redirect・OpenAI本家へのfallbackなし。TLS検証は常に有効。
- APIキーは環境変数、SigV4は承認済AWSプロファイル/SSO。プロファイル自体は信頼された管理設定であり、モデルには渡さない。
- Responsesはstore:false。function_callはホストで名前/引数/件数/時間/予算を検証。外部のサーバー側toolsは使用しない。
- 根拠を読まず、存在しない引用で行動候補を登録できない。人の承認前は確定タスクではない。
- 原文、引用、モデル出力をHTMLとして実行しない。Officeマクロ、埋め込みスクリプト、外部参照は実行しない。
- Native Messagingは指定extension IDとHTTPS hostのみ。明示操作、プレビュー付き。固定用途のstdio relayであり、任意コマンドの受付口ではない。
- 監査ログは固定の結果コードのみ。モデルreasoning、APIキー、原文、任意の例外本文をログにしない。

## 防御できない/別途必要なもの

**同じOSアカウントの悪意あるプログラム、管理者、EDR回避、OS侵害に対するサンドボックスではない。** 同一ユーザーならDBや設定を読める。SQLiteは本アプリでは暗号化していないため、BitLocker、会社所定ACL、バックアップ、端末保護、利用者ロックが必要。これを実装済みの暗号化と説明しない。

許可ルートの中に保存された文書を内容から完全に秘密情報分類する機構はない。APIキーらしい文字列を正規表現で消せば安全とも扱わない。取り込み対象を承認されたフォルダ・フロー・ページに限定する。文書内の悪意ある指示で誤った回答を生成する可能性は残るため、能力制限・根拠表示・人の確認を併用する。

クラウド資料のアクセス取消をリアルタイムには検知しない。既定24hのlease内にも窓がある。高機密資料ではこの方式が不適切な場合があり、管理者と許容時間を決める。元情報の再取得に成功したときだけleaseを更新する。PAの429や一時障害を根拠なくアクセス取消や正常な空データに変換しない。

失効/改訂時は索引・原本文字・引用候補・派生タスク・通知と会話キャッシュを保守的に消す。**SQLiteの削除は物理的な安全消去ではない**。WAL、空きページ、バックアップ、同期受渡JSON、Power Automate履歴、外部監査ログにコピーが残り得る。保存期間と廃棄手順を会社の規程で設計する。本体はクラウド原本や会社の既存ファイルを削除しない。

## 取り込みの信頼境界

受渡フォルダはそのフローと本人だけに書き込みを限定する。envelopeのmetadataは署名済の権限証明ではなく、承認済フローが実際に取得したという運用前提。任意の他人が書き込める共有フォルダを使わない。JSON/schema/event IDの検証は整合性の検査で、送信者認証の代わりではない。

sourcesを復活させるには、tombstoneより新しいobserved_atを持つ取得成功イベントが必要。ただし悪意ある同一ユーザーの偽イベントを防げるわけではない。必要なら企業署名と検証鍵配布を追加し、その管理基盤を別途審査する。

## 端末・データ・ログ

- `%LOCALAPPDATA%\WorkAssistant`は同期ルート外にする。公開repoで作業する場合、homeをrepo配下にしない。
- 常駐GUIかCLIの片方だけを起動する。複数ユーザー共有サービスとして公開しない。
- UIに表示された原文はスクリーンショット/クリップボード/開発ツールに転送され得る。会社のCodex自体の利用承認も必要。
- コアはPython標準ライブラリ中心だが、Python、Tk、SQLite、AWS SDK、pypdf、Windows relayを含めた依存の審査と更新は必要。
- Windows relayのコンパイルや実行が禁止されたら停止し、承認された署名済ビルド/配布経路を使う。ExecutionPolicy BypassやEDR停止はしない。

## 中止・解除

GUIを終了、CLI常駐ならCtrl+C。設定のbedrock.enabled/heartbeat_enabled/bridge_enabledをfalseにして再起動。必要なら`unregister-native-host.ps1`で本人のHKCU登録だけを解除する。ブラウザ拡張を無効化する。データ廃棄は会社の手順で実施し、自動的な安全消去が行われたとは扱わない。
